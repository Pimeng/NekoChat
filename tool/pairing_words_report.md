## 3. 生成与筛选流程

脚本：`tool/build_pairing_words.dart`（Dart，使用项目已有 `package:lpinyin`）。缺失的公开数据会自动下载到 `tool/data/`。

1. **候选池**：HSK 3.0 全表 11165 行，取出 2–4 个纯汉字、无变体竖线的词条 **9482** 条。
2. **词性过滤**：只保留名词性词条（含少量动词性名词）；剔除代词、副词、连词、介词、助词等纯功能词 → 丢弃 **4857** 条。
3. **常用字过滤**：每个字必须在一级字表 3500 字内 → 丢弃 **28** 条。
4. **读音校验**：用 `PinyinHelper.getPinyinE(word, separator: '')` 得到无调拼音，与 HSK 标注拼音（去声调、ü→v、去空格）比对；不一致即多音字/儿化/异读不稳定，丢弃 **99** 条。
5. **黑名单过滤**：负面、病痛、死亡、暴力、性、政治、宗教、歧视、脏话、专有名词（国家/城市/人名/品牌）、纯功能词、明显抽象/书面词 → 丢弃 **859** 条；另有 **4** 条词形重复。
6. **人工补充**：3 字具象词表 249 条（字表外 4 条、拼音异常等剔除后有效 **245** 条）；4 字常用成语表 215 条（字表外 7 条、负面成语 3 条剔除后有效 **205** 条）。
7. **选取与全表去重**：按“人工补充优先、HSK 等级由低到高、同等级词频由高到低”排序；2 字取 1510 条（因 3 字候选差 1 条，从 2 字补 1 条）、3 字 369 条、4 字 168 条。选取过程中因**无调拼音全表唯一**共跳过 **1654** 个同音候选。
8. **输出**：按字数分组、组内按无调拼音升序写入 `assets/pairing_words.json`（UTF-8 无 BOM、LF、2 空格缩进；含 `version`/`wordCount`/`generatedBy`/`license` 元数据）。

过滤统计来自生成脚本输出：`hsk.rows=9482, drop.not_noun=4857, drop.rare_char=28, drop.pinyin_mismatch=99, drop.blacklist=859, drop.duplicate_word=4, curated.rows.3=249, curated.rows.4=215, curated.drop.char=11, curated.drop.blacklist=3, 拼音冲突跳过=1654`。

## 6. 质量自评

- **同音歧义**：全表 2048 个词的无调拼音（lpinyin，ü 统一记 v，忽略声调）严格唯一。选取阶段跳过 1654 个同音候选，例如“公园/公元”只保留一个；3 字、4 字词也参与同一全局去重，不存在跨字数的同音冲突。
- **难打字/难听清**：所有字都在《通用规范汉字表》一级 3500 字内；没有生僻字、文言词、书面成语堆砌。4 字只收大众熟悉成语（画蛇添足、守株待兔、心平气和、温故知新等），3 字以向日葵、长颈鹿、巧克力、机器人、洗衣机、便利店等具象名词为主。
- **内容安全**：负面、病痛、死亡、暴力、性、政治、宗教、歧视、脏话、专有名词、纯功能词全部经字符级 + 整词级黑名单和人工复核剔除；主线复核指出的 13 个词与后续 4 个词已另行替换/标注。
- **已知取舍**：2 字词占多数（1511/2048 ≈ 73.8%），其中少量词（创意、含量、线索、专利、试题、体力等）偏抽象；它们都是高频、口语可说清、输入无歧义的常用词，用于凑满 2048 并保持覆盖面，但画面感弱于食物/动物/日用品等具象词。若想更“具象优先”，可在 App 端按语义标签加权，或把词表缩到约 1500 条只留具象词（仍满足 1500 最低要求，5 词熵约 52.7 bit）。
- **建议 App 侧实现**：词表作为 asset 由 `PairingWordList` 在启动时加载一次；使用 `Random.secure()` 做 5 次无放回抽样，展示时按词用空格分隔（输入时空格可省略）。

## 7. 复现方式

```powershell
# 生成（数据缺失时会自动下载 HSK 3.0 / jieba / 一级字表到 tool/data/）
dart run tool/build_pairing_words.dart

# 独立校验：元数据、2-4 汉字、一级字表、词形/拼音唯一、字数分布、30 词抽查
dart run tool/validate_pairing_words.dart
```

人工维护文件：`tool/data/exclude_words.txt`、`exclude_chars.txt`、`curated_3char.txt`、`curated_4char.txt`。修改后重跑脚本即可复现同样的 2048 行结构；若增删词导致某类候选不足，脚本会从 2 字池补齐并在输出中打印实际分布。
